# F.R.I.D.A.Y - AI Personal Assistant

A modular Python AI assistant with local LLM support via Ollama, persistent memory, and Vietnamese language support.

## Features
- 🤖 Local AI with Ollama integration
- 💾 Persistent conversation memory
- 🔒 File vault management
- 📝 Vietnamese support
- 🎯 Modular architecture

## Quick Start

```bash
# Setup
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# Run
python main.py
```

See [DEVELOPMENT.md](docs/DEVELOPMENT.md) for detailed setup instructions.
